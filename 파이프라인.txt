모델 프로토타입 전체 파이프라인

전체라인: 전처리 데이터 준비-> 모델 정의-> 학습-> 추론

> 전처리 데이터 입력(data_utils.py) \
함수명: **extract_all_tar** \
-지정된 train, test, val 하위 디렉토리의 .tar 압축파일을 찾아  
out 디렉토리(extracted)에 압축 해제 \
함수명:**DeepfakeSequenceDataset** \
-압축이 해제된 디렉토리에서 seq.pth 파일과 label이 담긴 json 파일을 매칭 해줌

---
> 모델 아키텍처 정의(model.py) \
클래스 정의:VIT_LSTM_Model \
역할: vit와 lstm을 결합한 모델을 결합한 아키텍쳐 \
-vit: 사전에 학습된 vit-Tiny 모델을 백본으로 설정, 전체 모델 중 이미지의 특징을 추출 하는 추출기 역할 \
-LSTM: vit가 각 프레임별로 추출한 feature 들을 순서대로 입력받음.lstm은 시퀀스 데이터의 시계열을 분석하여 미세한 변화나 부자연스러운 행동을 감지, 실질적으로 분류하는 역할

---
> 모델학습
-하이퍼 파라미터, 데이터 로더,손실함수, 옵티마이저 설정 \
- 학습모드와 검증모드로 모드 변경, 학습모드 시에서만 역전파 실행
